# 💳 Forage Midas - JPMC Software Engineering Virtual Experience

This project is part of the JPMorgan Chase & Co. Software Engineering Virtual Experience Program offered by Forage.

The project demonstrates backend software engineering concepts including transaction processing, REST APIs, Kafka messaging, and database integration using Java and Spring Boot.

---

## 🚀 Features

- 📌 REST API development using Spring Boot
- 📌 Real-time transaction processing
- 📌 Kafka event streaming integration
- 📌 Database connectivity and data handling
- 📌 Unit and integration testing
- 📌 Maven-based project structure

---

## 🛠️ Tech Stack

- **Java**
- **Spring Boot**
- **Apache Kafka**
- **Maven**
- **H2/MySQL Database**
- **REST APIs**
- **JUnit Testing**

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/PoreddiArpitha/forage-midas.git
cd forage-midas
```

### 2️⃣ Build the Project

```bash
./mvnw clean install
```

### 3️⃣ Run the Application

```bash
./mvnw spring-boot:run
```
